Commands
- uv sync - install dependencies
- uv run python manage.py runserver - start the dev server
- uv run python manage.py test - run the whole test suite

Rules
- Ask before adding any dependency
- Never commit secrets, .env, db.sqlite3 or .venv
- Commit regularly with clear messages
- Work on one task from backlog.md at a time

Documents
- _docs/plan.md - the product plan
- _docs/architecture.md - the architecture
- backlog.md - the task list
